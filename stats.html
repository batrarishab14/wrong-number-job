          How this page works

          1. A static game

            One HTML page on GitHub Pages. No login, no cookies, no tracking scripts.

          2. Anonymous events

            Each game adds a row to a Postgres table on Supabase. The public key can add rows but can't read, change or delete them, and the database rejects any score that doesn't add up.

          3. Totals only

            This page calls database functions that return counts and averages, never a single player's row. It refreshes every minute.

          • Static HTML + JS
          • Postgres row-level security
          • Insert-only public API
          • Server-side score check
          • 0 cookies
